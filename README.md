# SQL Exploratory Data Analysis - Layoffs Dataset

## Project Overview
This project explores a global layoffs dataset using SQL to identify trends across companies, industries, and countries.

## Key Questions
- Which companies had the highest layoffs?
- Which countries were most affected?
- How did layoffs change over time?
- Which companies had the highest layoffs each year?

## SQL Skills Used
- GROUP BY
- ORDER BY
- Aggregate Functions (SUM, MAX)
- Date Functions
- CTE (Common Table Expressions)
- Window Functions (DENSE_RANK)

## Key Insights
- Some companies experienced 100% layoffs.
- Certain countries had significantly higher layoffs.
- Layoffs showed noticeable monthly trends.

## Tools Used
- SQL
